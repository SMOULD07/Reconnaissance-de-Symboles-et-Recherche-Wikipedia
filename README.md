SymbolAI - Reconnaissance de Symboles et Recherche Wikipedia

Description Courte pour GitHub :
SymbolAI est une application interactive permettant de dessiner des symboles, de les reconnaître grâce à un modèle MLP, puis d'afficher des informations issues de Wikipedia sur le symbole identifié. Le projet intègre également une visualisation des liens externes et références sous forme de graphiques.

🛠️ Technologies utilisées :

Python (Tkinter, Scikit-learn, Wikipedia API, Matplotlib)
Modèle de reconnaissance basé sur un MLP (Multi-Layer Perceptron)
Visualisation des références via des graphes interactifs
🚀 Fonctionnalités principales :
✅ Interface pour dessiner des symboles
✅ Modèle IA pour reconnaître les symboles
✅ Recherche et résumé Wikipedia automatique
✅ Graphiques des liens et références
